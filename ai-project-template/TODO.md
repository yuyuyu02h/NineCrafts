- [x] 対応状態: **ローカル修正・検証済み（2026-10-22）**。初回は認識のみの指定で記録し、今回の死亡・復活の実装依頼に含めて対応。公開版には未反映。
- 報告日: 2026-10-21。
- 対象: 公開版 https://ninecrafts.pages.dev/ 。発生時のコミット・端末・ブラウザー・操作方式は未確認。
- ユーザー報告: 「海で自殺したらそのあとリスポーンしたら世界が斜めになっている」。
- 報告された発生手順: 海で死亡する → リスポーンする → 世界が斜めに見える。具体的な死亡原因と再現頻度は未確認。
- 期待する挙動: リスポーン後は水平な視界でプレイを再開できる。
- 確認状況: 当初はユーザー報告のみ。調査で被弾時のcamera.rotation.z加算に復帰処理がなく、死亡後も傾きが残る経路を確認。復活時の視点・速度・酸素リセットと被弾の傾きの減衰を実装。専用水中セーブで溺死→復活→水平な乾いた視界・HP20をブラウザ確認し、回帰テストも追加。元の公開プレイの端末・再現頻度は未確認。
- 関連工程: P07（死亡・復活と状態遷移）。水中の検証データで死亡・復活を確認済み。公開端末での追試は未実施。

### BUG-002 — タッチで視点を何周も回すとセーブの角度検証に失敗する経路

- [x] 対応状態: **ローカル修正・自動検証済み（2026-10-22）**。公開版には未反映。
- 発見元: P09の長時間プレイのコード確認。ユーザーからの追加報告ではなく、タッチのyaw加算に上限がなく、セーブは±2πまでしか許可しない不整合を確認したもの。
- 発生条件: タッチ視点を同方向へ繰り返し回し、yawが保存の許容範囲を超えてから保存する。実プレイでの再現操作は未実施。
- 期待: 回転数にかかわらず向きを保って保存できる。
- 対応: タッチ更新時と保存時にyawを±πへ正規化。100周相当の角度でも視線方向が一致し、保存範囲に収まる回帰テストを追加。
