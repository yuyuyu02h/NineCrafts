# プロジェクト情報

## 目的・対象

NineCrafts（画面上の名称: VoxelVerse）。採集・制作・戦闘・探索・建築を楽しむ1人用オープンワールドブロックゲーム。
PCとスマホの両方を対象に、まず進行保存・操作・資源収支・戦闘を正常化する。
PC 60fps／ミドルレンジスマホ30fps以上、約60分のカジュアルプレイは現時点の仮の評価基準。対象機種と正式な性能基準は未確定。

## 技術構成

- React 19 / TypeScript / Vite 8 / Three.js r170 / Tailwind CSS 4。Next.jsではない。
- ブラウザ内で完結するSPA。稼働中のバックエンド・認証・ランキングなし。
- 描画: Three.js、手続き生成テクスチャ、Web Audio合成。
- ホスティング先・本番運用環境は未確認。依存追加・外部サービス導入を前提にしない。

## 作業方針

- 正式な優先順と完了条件はTODO.md、技術判断はdocs/DECISIONS.md、再開情報はdocs/HANDOFF.mdで管理する。
- REVIEW.mdは2026-10-21時点の監査記録。修正後も歴史的な根拠として保存し、修正済み判定はTODO.mdに記録する。
- 既存のデザインと無関係な機能を変更しない。公開・購入・外部送信・データ削除は明示許可が必要。
- 前回の「REVIEW.mdのみ作成」はレビュー段階の制約。今回の実装依頼により、対象機能のソース・テスト・管理文書の変更は許可されている。

## 現状（開始時）

- 起動・地形・昼夜・建築・モブ・クラフト画面は存在する。
- 保存経路なし、アイテム消失、タッチ入力不足、無料クラフト、精錬複製などをREVIEW.mdで確認。
- Critical 3 / High 14 / Medium 11 / Low 1。これは開始時の件数で、現在の残件数ではない。
- P01〜P05: セーブ・ロード、数量保存、タッチ操作、材料消費・座標別精錬、道具の採掘段階を実装・検証済み。次はP06: 戦闘・昼夜。実機タッチ／性能判定はP15に残る。

## コマンド

- 開発: `npm run dev`（localhost:3000）
- 型チェック: `npx --no-install tsc --noEmit`
- Lint: `npm run lint`（現状は型チェックと同じ。ESLintは未導入）
- テスト: `npm test`（Node標準test runner＋既存tsx）。
- ビルド: `npm run build`。一時検証は`-- --outDir /private/tmp/ninecrafts-build`を付ける。
- ロック: bun.lockが既存の未追跡ファイルとして存在。無断で更新・削除しない。

## P01で追加された機能

設定画面の「今すぐ保存」、30秒ごとの自動保存、起動時の自動復元。保存エラーと読み込み失敗時の上書き保護を実装。
詳細な保存対象・検証結果・制約はTODO.md末尾のP01記録を参照する。

## P02〜P05で追加された機能

満杯時の受取拒否・部分取得、材料を消費する制作、燃料・調理時間・出力制限つきの座標別かまど、道具ランクと耐久を使う長押し採掘。
タッチ操作は開始画面／設定で切替可能。左スティック・右ドラッグ・採掘長押し・設置／使用・ジャンプ・走る・持ち物・一時停止に対応。ホットバーは狭い画面では横スクロールする。
保存形式v2はv1を互換移行する。現行の検証と実機未確認範囲はdocs/VALIDATION.mdを参照する。
